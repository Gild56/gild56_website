Gild Website API Documentation

Get top levels

/api/lists/[gild/server]/[classic/challenges]

Examples:

  • /api/lists/gild/classic
  • /api/lists/gild/challenges
  • /api/lists/server/classic
  • /api/lists/server/challenges

Get a level

/api/lists/[gild/server]/[classic/challenges]/[level name]

Examples:

  • /api/lists/gild/classic/Flashback
  • /api/lists/gild/challenges/Unnamed

Get players

  • /api/lists/players alphabetic order
  • /api/lists/players?sort=[key] reverted by default (from biggest to smallest)
  • /api/lists/players?sort=[key]&reverse=false without revert (from smallest to biggest)

Examples:

  • /api/lists/players?sort=levels_list_points
  • /api/lists/players?sort=server_challenges_list_points
  • /api/lists/players?sort=hardest_pos&reverse=false
  • /api/lists/players?sort=5_hardests_mean&reverse=false

Get a player

/api/lists/players/[player]

Examples:

  • /api/lists/players/Ihv2010
  • /api/lists/players/Gild56

Get top completed extremes

/api/lists/top_completed_extremes
